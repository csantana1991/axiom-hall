The boundary step eta equals one third is the first place the picture stops descending toward the minimizer in y. The y multiplier is 1 minus 2, which is negative 1. The y error flips sign and keeps its magnitude forever. From the origin, y goes to negative 0.8, where the error is negative 0.4. The next step flips that error back to positive 0.4, so y returns to 0. Then it returns to negative 0.8. The y coordinate oscillates between 0 and negative 0.8 and never approaches negative 0.4. Meanwhile x is fine: its multiplier is 1 minus two thirds, which is one third, so the x error is crushed quickly. Step 1 lands at x equals two thirds and y equals negative 0.8, function value 1/9 plus 3 times 0.16, which is about 0.111 plus 0.48, about 0.591. Step 2 lands at x equals eight ninths and y equals 0, function value about 0.012 plus 0.48, about 0.492. Later steps drive x to 1 and leave the function value sitting at 3 times 0.16, which is 0.48, forever, because the y piece never dies. A step that is not strictly below 2 over L can park you in a cycle. The cycle is not a second local minimum of the function. The function still has only one minimizer. The iteration simply refuses to approach it.

Cross the ceiling. Set eta equals 0.4. The y multiplier is 1 minus 2.4, which is negative 1.4, and the absolute value is bigger than 1. The x multiplier is 0.2, still contracting, since 0.4 is well below 1. From the origin, step 1: x equals 0.8, y equals negative 0.96, function value 0.04 plus 3 times the square of negative 0.56. The square is 0.3136, times 3 is 0.9408, and the function value is 0.9808, which is still below 1.48. A single step decreased the function. That one decrease does not certify the step. Step 2: x equals 0.96, y equals 0.384, function value about 1.846, which is already above the start. Step 3: y equals negative 1.498, function value about 3.614. Step 4: function value about 7.084. Step 5: about 13.88. Step 7: about 53.3. The y coordinate is running away, alternating sign, with magnitudes growing by 1.4 each step. The iteration has left every sublevel set. The function did not grow a second basin. The step left the region where the descent inequality protects you.

The descent inequality is worth saying with these numbers, because "below 2 over L" is otherwise a charm. At a point where the gradient has squared length 9.76 and the function equals 1.48, the smoothness bound says the next function value is at most 1.48 minus eta times the quantity 1 minus eta times L over 2, times 9.76. Here L is 6, so L over 2 is 3, and the quantity in the middle is 1 minus 3 eta. At eta equals 0.1, 1 minus 0.3 is 0.7, and 0.1 times 0.7 times 9.76 is 0.6832. The bound is 1.48 minus 0.6832, which is 0.7968. The actual value was 0.7168, which sits under the bound. At eta equals 0.2, 1 minus 0.6 is 0.4, and 0.2 times 0.4 times 9.76 is 0.7808. The bound is 1.48 minus 0.7808, which is 0.6992. The actual value was 0.3792, again under the bound. At eta equals one third, 1 minus 1 is 0, and the bound says the next value is at most 1.48. It promises no decrease. At eta equals 0.4, 1 minus 1.2 is negative 0.2, and the formula no longer promises a decrease. The algebra gives an upper number 1.48 plus 0.7808, which is 2.2608, and an upper number above where you started is not a descent certificate. The actual first step happened to fall, to 0.9808, and the second step rose past the start. The certificate and the accident are different objects. You want the certificate when you choose eta, and you want the trajectory when you check it.

A step of 0.5 separates the two axes cleanly. The x multiplier is 1 minus 1, which is 0. The first update from the origin sets x exactly to 1 and never moves it again. The y multiplier is 1 minus 3, which is negative 2. Step 1 sets y to negative 1.2 and the function value to 1.92, already above 1.48. Step 2 sets y to 1.2 and the function value to 7.68. Step 3 sets y to negative 3.6 and the function value to 30.72. Each step multiplies the y error by negative 2, so the function's y piece, which is 3 times the squared error, multiplies by 4. The values 1.92, 7.68, 30.72, 122.88 are that factor of 4 after the first step. The x coordinate is perfect the whole time. A plot that looks stable in x can still be a divergent iteration. You have to read the stiff coordinate.

The y step is the one that blows up first in a precise sense. Start already optimal in y, at x equals 0 and y equals negative 0.4, and use the dangerous eta equals 0.4. The y partial is 0, so y stays at negative 0.4. The x partial is negative 2. The update sends x to 0.8, then 0.96, then 0.992, with function values 1, then 0.04, then 0.0016, then 0.000064. The same eta that exploded the two-dimensional start is a fast, correct contraction when the stiff error is already zero, because 0.4 is below the x ceiling of 1. The explosion is not a property of the number 0.4 in isolation. It is a property of 0.4 times the curvature you still have left in the path. If you only probe a path that has no y error, you will approve a step the bowl does not allow.

The opposite probe is a path with no x error. Start at x equals 1 and y equals 0, function value 0.48, gradient 0 and 2.4. With eta equals 0.1, y goes to negative 0.24, then negative 0.336, then negative 0.3744, then negative 0.38976. The function values are 0.48, then 0.0768, then 0.012288, then about 0.001966. The multiplier 0.4 on the error is the whole story, and x never moves. With eta equals 0.4 from the same start, y goes to negative 0.96, function value 0.9408, already worse, then to 0.384, function value about 1.844, then to negative 1.498, and onward by factors of negative 1.4. You do not need a bad x coordinate to see the failure. The stiff axis is sufficient.

You might ask why we walk at all if one Newton step finishes a quadratic. Do the Newton step out loud so the question has a real answer underneath it, and then leave it. The second-derivative matrix is diagonal, with 2 in x and 6 in y. Its inverse divides the x partial by 2 and the y partial by 6. The x partial is 2 times x minus 1, so dividing by 2 returns exactly x minus 1. The y partial is 6 times y plus 0.4, so dividing by 6 returns exactly y plus 0.4. Subtracting those from the current point lands on x equals 1 and y equals negative 0.4 in one update, from any start. From the origin, you subtract negative 1 from 0 in the adjustment that the inverse prescribes, and you land at 1, and you subtract 0.4 from 0 in the y adjustment and land at negative 0.4. From the far point x equals 3 and y equals 2, the function value is 4 plus 3 times the square of 2.4. The square of 2.4 is 5.76, times 3 is 17.28, and the function value is 21.28. The gradient is 4 and 14.4. Divide by 2 and by 6, subtract 2 from 3 and subtract 2.4 from 2, and you are at the minimizer with function value 0. Gradient descent with eta equals 0.1 from that same far point takes a first step to x equals 2.6 and y equals 0.56, function value still large, and keeps walking. The Newton update used the curvatures 2 and 6 as divisors. Gradient descent uses one eta for both, which is why the stiffer curvature sets the schedule. We walk because the walk is what you will have when the loss is no longer a known quadratic, and because a failure of the walk, on this bowl, cannot be blamed on anything except the step and the sign.
