# Axiom Hall

Self-directed studio in computational finance and high-performance systems.

Ten degree courses, 36 credits, four semesters, ending in a lock-free single-producer single-consumer ring. Six standing courses (linear algebra, probability, calculus, data structures, systems, market vocabulary) are open beside the degree and do not count toward the 36.

This is not a Harvard, MIT, or any other degree. Course numbers echo public curricula. Capstone targets above one million events per second and under 250 nanoseconds are hypotheses for a compiled binary, not numbers this studio measures.

## Run

```bash
npm install
npm run dev
```

Progress stays in the browser. Seminar boards are spoken in the browser from the lecture scripts. They are not video files.
